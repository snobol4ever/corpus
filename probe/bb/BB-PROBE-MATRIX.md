**Relation to the other two instruments.** `BB-CHALLENGE-LADDER.md` holds the C

## Contrast pairs worth knowing before reading any failure

| pair | what it isolates |
|---|---|
| `L16` vs `L17` | `$` fires on a FAILED match (3 times, as the unanchored scan advances); `.` does not fire at all |
| `N13` vs `N14` | same contrast, inside an ARBNO body |
| `N05` vs `N06` | `$` on the ARBNO yields all 5 growth states; `.` yields only the final one |
| `N03` vs `N05` | capture INSIDE the body (per instance) vs ON the construct (per growth state) |
| `N08` vs `N09` | the outer-capture defect in both spellings — `$` and `.` fail identically |
| `A07`/`A08`/`A09` | ONE alternation site where arm 1, arm 2, and arm 3 respectively must be the arm resumed |
| `F03` vs `F05` | a `.` behind a FENCE does NOT survive a failed match; a `$` behind it already fired |
| `X05` | nested ARBNO with `.` at BOTH levels — only the last binding survives at each level |
| `D06` | `*P` is re-evaluated per match: same statement text, two different patterns |
| `X07` vs `X08`, `X09` vs `X10`, `D12` vs `D13` | the SPITBOL manual's own worked examples with their negative controls |



## FENCE0 vs FENCE1 — they are NOT the same construct

`FENCE` (nullary) is a **match-level abort**: backing into it fails the whole match.
`FENCE(P)` is a **local cut**: alternatives inside P stop being visible on backup, but components
BEFORE the fence are still retried. Probes `G00`/`G01`/`H01` are one subject built as a
discriminating triple — control `=S`, FENCE0 `=F`, FENCE1 `=S`. An implementation that collapses
one into the other fails exactly one leg.
