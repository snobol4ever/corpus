# gate_cases (prolog)

Every prolog test program the retired test_gate_*.sh scripts carried (DESIGN-PLAN gates-zero, CTO-637; Lon 2026-11-12 16:0x CST, verbatim: "It is time to DELETE all those damn scripts. ... We want of course to keep test cases."). Each file is `<gate>__<the file the gate wrote>`, extracted by the coo from the gate's heredocs and its one-line printf or echo writes, and from literal programs piped into scrip. Its answer is cut from the prolog oracle by util_build_package_suite.py --twice. A program the oracle cannot answer (a missing companion, an unexpanded shell variable, an oracle error, a hang) stays here as a file and is named in ALL.omit with the builder's reason.

The dialect column (the cfo 2026-11-13): an entry whose dialect cell is gnu had its ref cut from GNU Prolog 1.6.0 by gprolog_oracle_run.sh (util_build_package_suite.py reads the cell) and is graded with scrip --dialect=gnu; every other entry is cut from swipl. Eleven entries carry it, the cases whose retired gate expected gprolog's answer.

Every line under the oracle that answers it (the cfo 2026-11-14; skill prolog, reference section 4): a retired gate graded some lines by a ruling and not by an oracle, so one case could hold lines swipl answers, lines gprolog answers and lines only the standard states. Each check line now sits in an entry whose cell's oracle prints SCRIP's ruled answer: a case one oracle answers whole takes that oracle's cell (gnu, swi, or none for swipl with no switch); a case no one oracle answers is split by line, the split-off entry named after the case with a new suffix (`__control` beside `__body`, `__declared` beside `__conv`); a line only the standard states leaves the package and is graded where the standard's own suite grades it (the two current_predicate/1 error lines of the rung-3 case: logtalk_iso current_predicate_1 cases 08 and 11, INRIA current_predicate). A line that names the run directory is masked at the line in ALL.mask. Nine more gnu cells, one swi cell and two split-off entries came with this rule.
