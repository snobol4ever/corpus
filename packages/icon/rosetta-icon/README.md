# rosetta-icon

Every Icon solution of Rosetta Code, from RosettaCodeData (https://github.com/acmeism/RosettaCodeData) at 1d475861d 2026-07-16, Task/*/Icon/: 750 programs, each copied unchanged under its own file name (a -N for a second solution of a name). Rosetta Code's content is licensed GFDL 1.2; corpus is test data and never ships. TASKS.tsv maps each entry to its task. Every ref is cut from the language's oracle by util_build_package_suite.py --lang icon --twice (the grader 2026-11-13).
