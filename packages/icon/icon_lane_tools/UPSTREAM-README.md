# Icon Tools

* icondoc - a documentation generator for Icon programs, in the spirit of rdoc: see https://peterlane.codeberg.page/IconDoc.html
* icontags - generate a tags file for record/procedure definitions in one or more Icon files
* unicon.rb - an icon/unicon lexer for rouge: copy to lib/rouge/lexers/unicon.rb in gems/rouge-VERSION folder
* wiki-syntax - programs to add syntax highlighting to vimwiki generated html files: originally the Icon program called out to rouge for each code block, but this proved too slow, so a Ruby script handles all non-Icon blocks
