Generators in Icon

A procedure that suspends produces each of its results in turn:

procedure upto_n(n)
  local i
  every i := 1 to n do suspend i
end

procedure main()
  every write(upto_n(3) < 3 & "small")
  if *"abc" > 2 then write("long")
end

The same idea in Ruby, left as it stands:

def upto(n) = (1..n).each { |i| yield i }

Strings are scanned with ?:

"hello world" ? while tab(upto(&letters)) do write(tab(many(&letters)))
