# unicon_ipl -- the Unicon-only files of the Unicon program library that Unicon programs `$include` and `link`

Arizona's IPL (../ipl) has no posix.icn. Unicon's ipl/incl/posix.icn (the errno constants and WNOHANG/WUNTRACED as `$define`, `link posix`, `invocable` of the posix record types) and ipl/procs/posix.icn (the nine posix_* records) are copied here from /home/packages/icon/unicon/ipl, byte for byte unless a file says otherwise. SCRIP's `$include` search (icon_lex.c ipp_pathfind) looks here after Arizona's ipl/incl; the `link` search (icon_driver.c icn_link_open) looks in procs here FIRST for a Unicon program (a marker or --dialect=unicon) and after Arizona's ipl/procs for a plain Icon program. Not a graded package: no ALL.csv.

procs/xoptions.icn is Unicon's ipl/procs/xoptions.icn (the command-line option parser that general/xcommand and samples/xcommand link) with the semicolons SCRIP Icon requires inserted by the project's semicolon converter under Unicon's own Ender/Beginner rule; every other byte is upstream's.

procs/numbers.icn is Unicon's ipl/procs/numbers.icn (digsum over !string(i); it defines no max or min, they are Unicon builtins) with the semicolons SCRIP Icon requires inserted by the project's semicolon converter --compile-args=--dialect=unicon (197 inserted, audit clean); every other byte is upstream's.

gincl/keysyms.icn is Unicon's ipl/gincl/keysyms.icn byte for byte (the key codes $define, Shift_Tab and the key release codes among them, which Arizona's ../ipl/gincl copy lacks), for unicon_uni's gui/guidemos/explorer, named by an lpath line of unicon_uni's CONTRACT.tsv (officer_09 2026-11-16).

gprocs/ is the link closure of Unicon's ipl/gprocs/graphics.icn (25 files) and barchart.icn, which unicon_tests graphics/charting links: the files of /home/packages/icon/unicon/ipl/gprocs that a graphics program of unicon_uni, unicon_tests or rosetta-unicon links, so a Unicon program's `link graphics` reads Unicon's bevel, wopen, vidgets and the rest, never Arizona's (Arizona's bevel.icn lacks BevelDispose, which the gui classes call). Each file is semicolon-ready and its original's code, unicon -c ucode equal with the uid line dropped (officer_09 2026-11-17, row unicon-graphics-a-unicon-program-links-unicons-own-ipl-gprocs; the cqo's gprocs_check.sh --vendored-only). Ten are ../ipl/gprocs' converted copies, which prove equal to Unicon's originals (barchart color enqueue gpxlib imscolor vbuttons vmenu vradio vslider wopen); twelve are the cqo's conversion by util_icon_semicolons.py (harness history, e10e2594^) under --dialect=unicon (bevel gpxop graphics vcoupler vframe vidgets vlist vpane vscroll vstd vstyle window); dialog, vdialog and vtext are the same tool's conversion of Unicon's originals; viface.icn is ../ipl/gprocs' converted copy with Unicon's two differing lines applied by hand (VSetItems takes and passes flag). SCRIP's link search (icon_driver.c icn_link_open) reads procs here, then gprocs here, then Arizona's ipl/procs and ipl/gprocs for a Unicon program; a plain Icon program's search is Arizona's procs, procs here, Arizona's gprocs, as before.

mincl/evdefs.icn is Unicon's ipl/mincl/evdefs.icn byte for byte (the event codes `$define`, 210 lines), and mprocs/ holds the event-monitor library the same way as gprocs/: colormap, evinit, evnames, evsyms, evutils, opname and typebind of Unicon's ipl/mprocs, and printf, Unicon's own ipl/procs/printf.icn (its text differs from Arizona's, which the default search reads), which evnames links; kept in mprocs beside its one user so that no other package's printf moves. Each file has the semicolons SCRIP Icon requires, added by the mechanical road of skill unicon section 4 (util_icon_semicolons.py --compile-args=--dialect=unicon, 159, 31, 146, 138, 22, 102, 8 and 84 inserted) and each is the original's ucode by unicon 13.3 -c, the uid line aside (PROOF.tsv: same-code). They serve unicon_uni's udb/lib/memory_alloc, named by an ipath line (mprocs) and an lpath line (mincl) of that package's CONTRACT.tsv (officer_03, row unicon-uni-memory-alloc-finds-what-it-includes-and-links, 2026-11-17).

procs/ and gprocs/ hold the link closure of the 34 names a Unicon program's `link` used to find only in Arizona's ipl (array basename button capture clipping convert core ddfread escape evmux gener getpaths hexcvt image io ivalue lindgen makelsys navitrix options printf pscript random rational slider strings usage vsetup weavutil xcode xcompat ximage xio xutils; MEASURED over every package, /home/resources/saved-scratch/developer_11/link-fallback-carriers.tsv, class UNI_needs_across) and of the files those link in turn: 57 files of Unicon's own ipl/procs and ipl/gprocs (48 and 9), so that a Unicon program's link search is unicon_ipl alone and needs no Arizona folder; the first census missed nine files of eight more names (argparse base64 bincvt bold caseless findre fullimag iscreen, with itlib that iscreen links), linked by files of unicon_uni/lib, unicon_uni/udb, unicon_tests/uni_lib and unicon_tests/bench, which the before-and-after reading of the search edit found when unicon_tests lib/jsontests and unicon_uni xml/testxml turned red. Each is the semicolon-ready text by the mechanical road of skill unicon section 4 (util_icon_semicolons.py of harness history e10e2594^, run with --compile-args=--dialect=unicon), and each is its original's code by unicon 13.3 -c, the uid line aside (PROOF.tsv: same-code; the proof is /home/resources/progress/unicon-link-closure-developer_11/closure_check.sh); procs/io.icn is the copy ../uni_ipl/procs/io.icn holds, one hand edit, the `;` the converter put before a $ifdef the preprocessor drops (developer_11, row unicon-a-link-name-resolves-only-in-its-own-dialects-library).

mincl/patdefs.icn is Unicon's ipl/mincl/patdefs.icn byte for byte (the pattern-matching $define set, 109 lines; no statement, so no semicolon is owed), and mprocs/syntname.icn is Unicon's ipl/mprocs/syntname.icn with the semicolons SCRIP Icon requires, each by hand at the places the statement rule asks (the last statement before a closing brace has none, as unicon's own text), and its ucode by unicon 13.3 -c the same, the uid line aside (PROOF.tsv: same-code). Both serve unicon_uni's udb programs: patdefs.icn is $included by udb/evaluator.icn and udb/stepping.icn (lpath ../unicon_ipl/mincl), syntname.icn is linked by udb/lib/failedloop.icn and udb/lib/looptime.icn (ipath ../unicon_ipl/mprocs). The four entries were red for want of these two files, which the oracle found in its own library (the four udb drivers, one cause family: the closure of the package, this row).
