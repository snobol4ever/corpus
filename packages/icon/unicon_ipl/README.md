# unicon_ipl -- the Unicon-only files of the Unicon program library that Unicon programs `$include` and `link`

Arizona's IPL (../ipl) has no posix.icn. Unicon's ipl/incl/posix.icn (the errno constants and WNOHANG/WUNTRACED as `$define`, `link posix`, `invocable` of the posix record types) and ipl/procs/posix.icn (the nine posix_* records) are copied here from /home/resources/unicon/ipl, byte for byte unless a file says otherwise. SCRIP's `$include` search (icon_lex.c ipp_pathfind) looks here after Arizona's ipl/incl; the `link` search (icon_driver.c icn_link_open) looks in procs here FIRST for a Unicon program (a marker or --dialect=unicon) and after Arizona's ipl/procs for a plain Icon program. Not a graded package: no ALL.csv.

procs/xoptions.icn is Unicon's ipl/procs/xoptions.icn (the command-line option parser that general/xcommand and samples/xcommand link) with the semicolons SCRIP Icon requires inserted by harness/scripts/util_icon_semicolons.py under Unicon's own Ender/Beginner rule; every other byte is upstream's.

procs/numbers.icn is Unicon's ipl/procs/numbers.icn (digsum over !string(i); it defines no max or min, they are Unicon builtins) with the semicolons SCRIP Icon requires inserted by harness/scripts/util_icon_semicolons.py --compile-args=--dialect=unicon (197 inserted, audit clean); every other byte is upstream's.

gincl/keysyms.icn is Unicon's ipl/gincl/keysyms.icn byte for byte (the key codes $define, Shift_Tab and the key release codes among them, which Arizona's ../ipl/gincl copy lacks), for unicon_uni's gui/guidemos/explorer, named by an lpath line of unicon_uni's CONTRACT.tsv (officer_09 2026-11-16).

gprocs/ is the link closure of Unicon's ipl/gprocs/graphics.icn (25 files) and barchart.icn, which unicon_tests graphics/charting links: the files of /home/resources/unicon/ipl/gprocs that a graphics program of unicon_uni, unicon_tests or rosetta-unicon links, so a Unicon program's `link graphics` reads Unicon's bevel, wopen, vidgets and the rest, never Arizona's (Arizona's bevel.icn lacks BevelDispose, which the gui classes call). Each file is semicolon-ready and its original's code, unicon -c ucode equal with the uid line dropped (officer_09 2026-11-17, row unicon-graphics-a-unicon-program-links-unicons-own-ipl-gprocs; the cqo's gprocs_check.sh --vendored-only). Ten are ../ipl/gprocs' converted copies, which prove equal to Unicon's originals (barchart color enqueue gpxlib imscolor vbuttons vmenu vradio vslider wopen); twelve are the cqo's conversion by util_icon_semicolons.py (harness history, e10e2594^) under --dialect=unicon (bevel gpxop graphics vcoupler vframe vidgets vlist vpane vscroll vstd vstyle window); dialog, vdialog and vtext are the same tool's conversion of Unicon's originals; viface.icn is ../ipl/gprocs' converted copy with Unicon's two differing lines applied by hand (VSetItems takes and passes flag). SCRIP's link search (icon_driver.c icn_link_open) reads procs here, then gprocs here, then Arizona's ipl/procs and ipl/gprocs for a Unicon program; a plain Icon program's search is Arizona's procs, procs here, Arizona's gprocs, as before.
