= pcl library title page

This is a collection of programs/library files I have created for use in Icon /
Unicon programs. The documentation has been generated using link:/IconDoc.html[icondoc].

* Download and unzip the https://codeberg.org/peterlane/icon-libs/releases[latest release] - the library itself is in the folder "pcl".

Individual files can be extracted and used in programs, or the whole collection installed for use with `link`.

Install as library:

* For Windows, there is an "install.bat" script: alter the pathnames at the top of the file and run to compile and install.
* Alternatively, compile into .u* files:
----
> cd pcl
> icont -c *.icn
> cd ..
----
* Place the "pcl" folder of compiled code onto your IPATH
* Optionally test the libraries by compiling and running "pcl_test.icn"

Use:

----
link statistics

procedure main()
  lst := [1,2,3,4,5,6]
  avg := arithmetic_mean(lst)
  write ("Average of list is: ", avg)
end
----
