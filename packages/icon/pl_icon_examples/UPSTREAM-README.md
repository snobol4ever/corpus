# Examples of Icon code

Small pieces of code collected for various reasons:

* algorithms - implementations of code from the book _Beginning Java Data Structures and Algorithms_ by James Cutajar, 2018
* examples - random demonstrations/tests
* graphs - implementation of graph searching / path finding algorithms
* id3 - my first real use of Icon, implementing some simple data analysis for my MSc project
* vidgets - examples of using the built-in vidgets library, see https://peterlane.codeberg.page/Vidgets.html
