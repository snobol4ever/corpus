# sno_bintree (Snobol4BinTree)

ad2108's traverse-binary-tree-in-snobol4 (https://github.com/ad2108/traverse-binary-tree-in-snobol4, commit 21c82c0 of 2026-07-05, MIT): one
program that builds and traverses a binary tree, read in place (`ALL.source`), upper-cased in place by `sno_upcase_edition.py` (25 lines).
SPITBOL ends it with error 022, a function the program calls by a name it never defines in that case; that error is its answer.

The first SCRIP reading (mode 3, SCRIP 38179ce886): 0 of 1.
