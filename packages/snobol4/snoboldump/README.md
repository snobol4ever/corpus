# snoboldump (Snobol4Dump)

James P. D.'s SNOBOLDump (https://github.com/James-P-D/SNOBOLDump, commit f7271c0 of 2021-11-06, MIT): five programs written while learning
SNOBOL4 (hello, data, control, input and output, matching), read in place from `/home/packages/snobol4/snoboldump`
(`ALL.source`). Their DOS names (`.SNO`) were written in lower case by `sno_upcase_edition.py`, which found no line to change. Every answer
is `sbl -bf`'s, cut twice by the mine road; `03_IO` ends with SPITBOL's error 116 (a DOS file name), graded as its answer.

The first SCRIP reading (mode 3, SCRIP 38179ce886): 5 of 5.
