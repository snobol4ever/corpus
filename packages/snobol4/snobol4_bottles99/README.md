The 99 Bottles of Beer programs in SNOBOL4 and SPITBOL from 99-bottles-of-beer.net, the Web Archive's copies (the live site no longer resolves), read in place from
/home/packages/snobol4/snobol4_bottles99 (the grader 2026-11-20; Lon named the source: "99 Bottles of Beer"). Cut by util_build_package_suite.py --mine, twice on the oracle.

The programs are upcased in place by sno_upcase_edition.py (Lon 2026-11-15: built-in names, keywords and goto letters to upper case, the spacing kept; UPCASE.tsv names each line changed), since five are written for a case-folding SNOBOL4.
