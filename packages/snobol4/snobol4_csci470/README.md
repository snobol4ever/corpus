# snobol4_csci470

The SNOBOL4 examples of Robert Lowe's CSCI 470, Comparison of Programming Languages (University of Tennessee Martin, Spring 2026; MIT licence),
the `snobol4` folder of github.com/utm-lowe/CSCI470-Spring-2026-Examples at 73e3f8c, read in place from /home/packages/snobol4/csci470_lowe
(the grader 2026-11-22; Lon: "continue cutting, grading, and scoring."). Cut by util_build_package_suite.py --mine, twice on the oracle.

The programs are written for CSNOBOL4, which folds case, so they are upcased in place by sno_upcase_edition.py (Lon 2026-11-15: built-in names,
keywords and goto letters to upper case, angle-bracket subscripts to square brackets, the spacing kept; snobol4/UPCASE.tsv names each file changed).
The repository's `.local` folder is a CSNOBOL4 2.3.3 installation and is not cut here: CSNOBOL4's own tests are the package csnobol4_suite.
