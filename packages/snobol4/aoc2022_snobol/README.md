# aoc2022_snobol (Advent of Code 2022 in SNOBOL4)

Advent of Code 2022, day 1 part a, by Francesco Stiffoni (https://github.com/fstiffo/aoc-2022-snobol, commit 444971e, MIT), written for Oregon SNOBOL5.
The one program of the repository. NOT HOSTED: its file carries the puzzle input, read in place from /home/packages/snobol4/aoc2022_snobol (ALL.source).
The input after END is fed as standard input (ALL.stdin, day1.input in the root). Cut by sbl -bf twice, the same answer (the grader 2026-11-18,
on Lon's "let's go" for Advent of Code in every language).
