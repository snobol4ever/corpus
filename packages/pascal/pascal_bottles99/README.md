# pascal_bottles99

The 99 Bottles of Beer programs in Pascal, Delphi, Free Pascal, Turbo Pascal, Irie, TMT and PascalX from 99-bottles-of-beer.net, the Web Archive's copies (the live site no longer resolves), read in place from
/home/packages/pascal/pascal_bottles99 (the grader 2026-11-20; Lon named the source: "99 Bottles of Beer"). Cut by util_build_package_suite.py --mine, twice on the oracle.

The oracle is fpc on its mode ladder, then GNU Pascal (--mine-dialects iso,fpc,objfpc,delphi,tp,gpc).
