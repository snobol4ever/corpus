# Rosetta Code -- Delphi (rosetta-delphi)

Every Delphi solution on Rosetta Code, vendored from the RosettaCodeData project (https://github.com/acmeism/RosettaCodeData, commit 1d475861d, Task/*/Delphi/),
944 programs, one file per solution, each copied unchanged (a character outside [A-Za-z0-9._-] in its name became _). TASKS.tsv maps each to its task.
Rosetta Code's content is published under the GNU Free Documentation License 1.2. Graded against fpc 3.2.2 on the mode ladder (ISO, default, objfpc, delphi, tp),
as rosetta-pascal is (CONTRACT.tsv dialect any-fpc-mode). Cut by the grader 2026-11-18 (Lon: "Ensure we have all the Rosetta collections for SCRIP's languages").
