# rosetta_live_pascal

Rosetta Code's Pascal, Delphi, Free_Pascal solutions that the RosettaCodeData dataset of the rosetta packages lacks, fetched from the live site and read in place from /home/packages/pascal/rosetta_live_pascal
(the grader 2026-11-20; Lon: "find, cut, grade, and score programs and packages"). Cut by util_build_package_suite.py --mine, twice on the oracle.

Pascal, Delphi and Free Pascal in one package, a folder each; fpc on its mode ladder, then GNU Pascal (--mine-dialects iso,fpc,objfpc,delphi,tp,gpc).
